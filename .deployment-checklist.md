## ⚙️ Step 2: Deploy Backend

- [ ] Connected to VPS: `ssh root@your-vps-ip`
- [ ] Navigate to scripts: `cd /root`

- [ ] Entered database password when prompted
- [ ] Entered Google Client ID (or used default)
- [ ] Script completed without errors

### Verify Backend
- [ ] Backend service running: `systemctl status xperience-backend`
- [ ] Backend responds: `curl http://localhost:8080/actuator/health`

- [ ] No errors in logs: `journalctl -u xperience-backend -n 20`

## 🔐 Step 9: Security & Backup

### Security
- [ ] Changed default SSH port (optional but recommended)
- [ ] Configured firewall:
  ```bash

  ```
